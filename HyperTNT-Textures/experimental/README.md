# Mapping от разработчика ядра — экспериментальный

`hypertnt-21-pdc-mapping.json` получен от разработчика PurpurBedrock без изменений. Требует одновременно подходящий `custom_model_data` и строку PDC `hypertnt:tnt_type` (для базового типа значение `tnt`). Он предназначен только для конкретной доработанной версии ядра, поддерживающей `predicate_strategy` и `server_pdc_string`; поддержка обычным Geyser и существующей сборкой PurpurBedrock не подтверждена. Не устанавливайте поверх рабочего mapping без подтверждения разработчика ядра и теста.

Разработчик сообщил о проверке сетевых ID на двух синтетических клиентах, но не о проверке отображения текстур в игре. Интеграция установленных блоков и тестовый JAR ядра ещё не готовы. Оригинальный mapping формата 1 остаётся отдельно и не требует PDC; нельзя включать оба mapping одновременно без проверки конфликтов.
